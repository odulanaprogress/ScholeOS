# ScholeOS

> Modern Operating System & Unified Management Platform for Schools.

ScholeOS handles results, continuous assessments, broadsheets, fee collection, attendance, and parent communication — engineered specifically for the realities of school administration.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + CSS Variables
- **Icons:** Lucide React
- **Design Tokens:** Warm Cream (`#FBF0E1`), Surface White (`#FFFFFF`), Primary Indigo (`#4338CA`), Warm Gold (`#D4A017`), Dark Charcoal (`#1E1B1A`)
- **Typography:** Google Fonts Poppins (Display) & Inter (Body)

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Running Locally
```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.
